# Customer Churn Analysis

## Project Overview

This project analyzes customer churn using data analysis, machine learning, and business intelligence techniques.

## Objective

The objective is to identify customer churn patterns, understand the factors associated with customer attrition, and present actionable insights through data analysis and visualization.

## Tools & Technologies

- Python
- Excel
- Power BI
- Jupyter Notebook

## Project Files

| File | Description |
|---|---|
| `AIFM PROJECT MARKETING.ipynb` | Data analysis and machine learning notebook |
| `Churn-analysis dashboard.pbix` | Interactive Power BI dashboard |
| `customer_data_with_churn_new.xlsx` | Customer dataset |
| `customer_data_with_predictions.csv` | Prediction results |
| `churn analysis.png` | Dashboard screenshot |
| `churn-analysis.png` | Analysis screenshot |

## Analysis Performed

- Data cleaning and preprocessing
- Exploratory data analysis
- Customer churn analysis
- Machine learning-based churn prediction
- Power BI dashboard development
- Business insight generation

## Key Business Questions

- What percentage of customers are churning?
- Which customer segments show higher churn?
- What factors are associated with customer churn?
- Which customers may be at higher risk of churn?
- How can businesses use these insights to improve customer retention?

## Business Value

The analysis provides data-driven insights into customer churn and can help businesses identify high-risk customer segments and develop targeted customer retention strategies.
